# CloakOS

Part of [Cloak](https://usecloak.org), the human-centric AI platform.

CloakOS is shifting focus. The original Anki Vector brain now lives in
[`vector-edition/`](vector-edition/) as **CloakOS Vector Edition**. It isn't part of the default
CloakOS download; install it on its own:

```bash
curl -fsSL https://raw.githubusercontent.com/UseCloakAI/CloakOS/main/vector-edition/install.sh | bash
```

## Shell

[`shell/`](shell/) is the native CloakOS UI prototype (Flutter + liquid glass), starting on macOS.
